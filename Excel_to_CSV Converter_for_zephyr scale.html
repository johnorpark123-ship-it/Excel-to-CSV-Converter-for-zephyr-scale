사용 방법 (반드시 읽어주세요)

※ 주의: 업로드할 엑셀 파일은 반드시 '암호화 해제' 상태여야 합니다!

1. 우측 상단의 [템플릿 다운로드] 버튼을 눌러 양식을 받습니다.

2. 시트명은 영문 또는 한글 문자열과 숫자가 조합된 [문자열]-[숫자열] (예: PXW-106, 한글-123) 규칙으로 작성해야 인식됩니다.

3. D3 셀은 [티켓번호] 유저스토리 제목 (예: [PXW-106] 로그인 기능) 형식으로 작성합니다.
   ※ D3의 티켓번호와 시트명이 불일치하면 변환 시 경고가 발생하며, 대괄호 형식이 없으면 D3 전체 텍스트가 제목으로 사용됩니다.

4. Depth #2 열에 값이 있으면 새로운 테스트 케이스의 시작(순번 증가)으로만 인식합니다. 실제 스크립트 내용은 Procedure, Pre-condition, Expected Result 열의 데이터만 매핑됩니다.

5. 여러 개의 엑셀 파일을 동시 업로드하여 하나의 CSV로 병합 가능합니다.
