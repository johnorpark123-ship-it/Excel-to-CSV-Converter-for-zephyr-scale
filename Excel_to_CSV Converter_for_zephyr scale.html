사용 방법 (반드시 읽어주세요)

※ 주의: 업로드할 엑셀 파일은 반드시 '암호화 해제' 상태여야 합니다!

1. 우측 상단의 [템플릿 다운로드] 버튼을 눌러 양식을 받습니다.

2. 시트명을 [문자열]-[숫자열] (예: PXW-106) 규칙으로 작성합니다.

3. 숨김 처리된 시트는 자동 무시되며, 데이터가 있는 시트만 추출됩니다.

4. Depth #2, Procedure, Pre-condition, Expected Result 열의 데이터를 기반으로 스크립트가 매핑됩니다.

5. 여러 개의 엑셀 파일을 동시 업로드하여 하나의 CSV로 병합 가능합니다.
